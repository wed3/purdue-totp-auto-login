Purdue TOTP Auto Login

Version 0.2.0

Click Auto log in once to start. You can enter your password yourself, or enable one-click mode below.

Authenticator setup

  1. Open Microsoft Security Info and sign in with your Purdue account.
  2. Select Add sign-in method, then Authenticator app.
  3. Select I want to use a different authenticator app.
  4. Select Can't scan QR code? and copy the Base32 secret key.
  5. Paste it below, save, then use the test code to finish enrollment.
